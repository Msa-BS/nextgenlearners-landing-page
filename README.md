# NextGenLearners – Week 3 Task 3

## Current Openings

A dynamic internship programs page built for the NextGenLearners Week 3 Task 3.

## Features

- Displays internship programs dynamically from `programs.json`
- Search programs by domain
- Search programs by skill
- Real-time filtering
- Responsive Bootstrap card layout
- Skill badges
- Program duration
- Apply Now buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Bootstrap 5
- Font Awesome
